## 首轮失败与修正

首轮选择被通用词污染：Knowledge-first mean 2119.42，7 个任务更长。该结果保存在 `results-first-pass.json`。随后只修改确定性选择规则：

- 排除通用中英文词；
- 精确 `NC*` 标识符优先；
- 指定组件时排除不匹配的 component API；
- 每个 Context 最多选择 6 个 published unit；
- 命中知识时保留最多 3 个 Raw fallback。

固定任务与验收字段未改变。

## 结论边界

本数据支持“在这 12 个固定任务中，最终 Knowledge-first Context 字符估计更短且 must-recall 字符串仍可见”。它不支持真实 token 节省、代码质量提升、人工时间降低或生产 ROI 结论。
