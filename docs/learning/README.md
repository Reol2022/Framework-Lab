## 事实等级

- **已验证**：有测试、运行记录或可定位代码证据。
- **已实现，未做真实外部验证**：代码和单测存在，但尚未在第二框架或真实用户环境验证。
- **未实现/规划中**：不得作为简历完成项或运行结果描述。

## 更新规则

每次版本、Bug 修复或重构结束后，在 `changelog/YYYY-MM-DD.md` 记录目标、修改、调用链、故障、验证、风险和新增面试题。不得把本地绝对路径、原始大型日志、凭据或未脱敏 Agent 会话写入本目录。

当前项目没有数据库、HTTP 后端、生产部署、Docker/Nginx、LLM API、Embedding 或向量数据库实现；相关主题将只在确认真实需求后记录。
