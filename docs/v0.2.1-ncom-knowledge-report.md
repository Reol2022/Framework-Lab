# NCom v0.2.1 Knowledge Report

已发布 6 个结构化 Knowledge Unit：

- `ncom-package-public-exports`
- `ncom-component-base-model`
- `ncom-event-system`
- `ncom-ncbutton-api`
- `ncom-ncinput-events`
- `ncom-example-workflow`

全部为精确 commit Scope、至少一个可定位 Evidence、Schema 校验和显式 review 后的 `observed` Claim。它们不把静态观察写成 runtime 验证，也不把内部实现自动升级为公共 API。

一个全新外部 Codex 学习会话曾只读取 NCButton Bundle 并生成草稿；其输出因不符合 FrameworkKnowledgeUnit Schema 被拒绝导入。随后使用同一 Bundle Evidence 完成字段规范化、独立校验和人工审核。这证明 Handoff 可用且 Draft 防线会阻止未结构化输出直接发布。
