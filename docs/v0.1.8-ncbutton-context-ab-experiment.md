# Framework Lab v0.1.8：NCButton 开发任务 Context A/B 实验

日期：2026-07-23

## 实验目的与边界

验证 v0.1.7 生成的任务级 Agent Context 能否在全新 Coding Agent 会话中减少陌生框架探索、帮助保持修改边界，并支持完成真实 NCom 开发任务。

本实验是单框架、单任务、双会话的探索性对照，不具有统计普遍性。实验不验证自动 Agent 调用能力；Context 由用户交付给 B 组会话。

## 任务与环境

任务是在 NCom example 中新增 NCButton 基础示例，展示普通按钮、禁用按钮和点击事件处理。

- Framework：NCom
- Commit：`a350b576bbeae6c6254273037a17d2a8730fb80f`
- Package manager：pnpm `10.26.1`
- A 组：无 Framework Lab Context
- B 组：使用 v0.1.7 `ncom-ncbutton-example` Context
- 两组：相同 commit、独立 detached worktree、全新 Coding Agent 会话、无此前排障对话、无子 Agent

修改约束为：不修改 `packages/`、`package.json`、`pnpm-lock.yaml`、构建配置或依赖；只修改必要的 example 文件；不 commit、不 push。

B 组 Context 的 Manifest 绑定该精确 commit 和 retrieval business hash `sha256:344ea22363309015a26419fb3c7cc43a41c4f89516ac44e7769b59d9947d4944`。Context 的启发式估算为 3,676 tokens，包含 NCButton 公共导出、`@ncom/all` 导入、`disabled`、`nc-click`、事件绑定示例、相关类型/文档/示例、pnpm 版本和修改约束。

## A 组观察

A 组注册“12.基础用法”，实现普通、禁用和监听 `@nc-click` 的按钮；点击处理使用公共导出的 `ClickEventDetail`，并更新页面结果文本。

Agent 自行定位或搜索了组件与 Props、基础事件、公共导出、Button 文档和示例、example 路由与菜单、Vite、package scripts、TypeScript 和 Prettier 配置。附件记录的验证结果为 Prettier、`git diff --check`、主题构建、example 构建、开发服务和 HTTP 200 通过；真实点击未验证。

## B 组观察

B 组直接使用 Context 中的 `@ncom/all`、`disabled`、`nc-click` 和事件绑定写法，只补充检查目标 example 的注册入口、示例编号、相邻代码风格、build/dev scripts 和浏览器验证方式。

实现完成普通、禁用和点击按钮，但没有使用 Context 召回的 `ClickEventDetail` 或事件对象，以 `alert` 作为反馈。初次 example build 因主题 CSS 尚未生成失败；执行主题构建后，第二次 example build 通过。开发服务与 HTTP 200 通过；真实点击未验证。

## 暴露的 Context 缺口

1. 验证命令链不够明确。后续任务包应按证据提供主题构建、example 构建、example dev 的顺序。
2. 验收标准不够结构化。点击任务应明确是否要求公开事件类型、页面可观察状态，以及是否禁止以 `alert` 作为唯一反馈。
3. 指标采集不足。文件读取、重复读取、搜索命令、命令总数、耗时、会话 usage 和压缩次数均未精确保存；无法获得的数据应保持 `null`。

## 证据支持与不支持

本次实验支持：

1. v0.1.7 Context 可由全新 Coding Agent 会话使用。
2. 有 Context 的 Agent 可完成真实 NCom example 开发并通过构建。
3. Context 将补充探索集中到目标 example 的落地结构和验证命令。
4. 两组均保持修改边界。

本次实验不支持：

- 稳定降低固定比例 Token；
- 提升所有任务成功率或代码质量；
- 对所有框架和任务有效；
- 浏览器交互已通过自动化验证；
- 检索效果具有统计稳定性。

## 后续方向

后续版本应优先提供结构化任务/验收、独立 worktree、任务包交付、diff 与边界采集、验证命令链、候选结果、对照报告和可获得指标采集。暂不把本实验表述为 Codex API 集成或浏览器自动化能力。
