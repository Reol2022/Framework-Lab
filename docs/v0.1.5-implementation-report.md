# v0.1.5 框架源码与文档采集实施报告

日期：2026-07-23

## 实施结果

实现 `catalog scan/validate/list/diff`。扫描输入严格来自 `git ls-files -z`，默认拒绝 tracked dirty worktree；未跟踪和忽略文件不进入 Catalog。文件使用有限并发和流式 SHA256，输出先写入临时目录，Schema 全部通过后原子移动。

Catalog 记录文件元数据、确定性分类、pnpm/npm/yarn workspace package、依赖和导出目标、Markdown 章节/链接/代码块、示例入口及判断依据、静态配置和高/中置信度关系。不执行仓库脚本、不动态 import 配置、不抓取外部链接，也不生成架构结论。

## 确定性

`rootHash` 只使用按路径排序的 `path + file sha256 + category + packageId`。时间、绝对路径和文件系统遍历顺序不参与计算。相同 NCom commit 连续扫描得到相同 rootHash，第二次扫描识别已有且内容一致的 snapshot，没有覆盖。

## 验证

固定 pnpm 10.26.1 执行 lint、test、typecheck 和 build。测试总数为 126，其中新增 Catalog fixture 测试 66 项；旧 baseline、errors、knowledge 和 context 测试全部通过。fixture 位于临时 Git 仓库，覆盖中文和空格路径、编码、二进制、大文件、分类、workspace、Markdown、示例、配置、manifest、diff、dirty 拒绝和重复扫描。

## 边界

Catalog 不是语义知识库，不包含 TypeScript AST、类/接口/函数、组件 Props/事件或语义检索。它不自动创建知识卡、不驱动 Coding Agent，也没有验证 token 节省或第二个真实框架。
