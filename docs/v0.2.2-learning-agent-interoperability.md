# v0.2.2 Learning Agent 互操作

`learn handoff` 现在在 Bundle 目录写入：

- `agent-instructions.md`：必填字段、枚举、Evidence 限制、禁止 Markdown 包装、80 KiB 上限和机器可读错误码；
- `draft-template.json`：可通过 Schema 的最小 JSON 形状；
- `handoff.json`：本地预校验命令和错误码清单。

外部 Agent 只能使用 Bundle Evidence Index 中的 id。返回文件应执行：

```powershell
pnpm framework-lab learn import ncom <bundle-id> --input <draft.json> --dry-run
pnpm framework-lab learn import ncom <bundle-id> --input <draft.json>
pnpm framework-lab learn validate ncom <knowledge-id>
```

前两步分别是无写入预校验和显式导入。Framework Lab 不自动调用外部 Agent，因此本报告不把模板生成等同于外部会话互操作已完成。
