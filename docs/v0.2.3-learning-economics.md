# Framework Lab v0.2.3 学习成本与复用收益

## 口径

`learn economics ncom` 对 22 个 Published Knowledge 分别记录 Bundle、Draft、Published Knowledge 的字符启发式 estimated tokens、review 次数、任务命中、复用次数、被替代 Raw 字符数、Context 差值和 break-even estimate。结构化结果见 `frameworks/ncom/learning/economics.json`。

估算公式为 `ceil(characterCount / 4)`。它不包含模型内部推理、缓存、人工审核时间或账单 Token；Bundle 文件在本地不存在时，对应字段为 `null`，不会补造数值。

## Agent 会话事实

Demo B 的 Knowledge-first 会话没有搜索命令，Raw 会话有 2 次搜索；但 Knowledge-first 的读取命令和 agent-reported input tokens 更高。Context 文件更短不等于整个 Coding Agent 会话 token 更少，单样本也不支持总体节省结论。
