# NCom 组件约定审计

日期：2026-07-23
源码 commit：`a350b576bbeae6c6254273037a17d2a8730fb80f`

## 已观察结构

- 基础 Web Component 类为 `packages/core/src/component.ts` 中的默认导出 `NComponent extends HTMLElement`。
- 多数组件是 `packages/components/src/<component>/index.ts` 中默认导出的 `NC*` class，直接继承 `NComponent`。
- 表单输入类组件可继承 `packages/components/src/form/baseinput.ts` 中的 `NCBaseInput extends NComponent`。
- 组件通常调用从 `@ncom/core` 导入的 `defineComponent(tag, class)` 注册。
- `packages/components/index.ts` 汇总组件和类型；`packages/all/index.ts` 再导入并导出这些符号。
- 同目录样式通常为 `style.scss`；form/grid 等目录也存在以组件角色命名的 SCSS。
- 显式 Props 模型存在于部分 `types.ts/type.ts` 中，常见名称为去掉 `NC` 前缀后的 `<Name>Props`，但不是每个组件都有。
- 自定义事件可由 `eventManager.addSelfEvent("name", ...)` 的静态字符串定位。
- slot 可由 class 模板字符串中的 `<slot>`/`<slot name="...">` 定位。
- 生命周期覆盖包括 `connectedCallback`、`disconnectedCallback`、`attributeChangedCallback` 及基类声明的 `firstUpdated/updated/displayCallback/hideCallback`。
- 示例位于 `example/component/<component>/`；组件文档位于 `doc/api/components/<component>.md`。

这些规则来自上述源码结构，不表示所有未来 NCom commit 都保持相同约定。
