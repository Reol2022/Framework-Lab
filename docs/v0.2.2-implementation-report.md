## 范围

本版本把已存在的 Catalog Snapshot 与 Symbol Snapshot 绑定为 `FrameworkVersion`，并复用既有差异结果生成结构化证据、Claim 和知识单元影响记录。它不执行框架源码、不自动修改框架源码、不自动发布知识，也不调用外部 Agent 或 OpenAI API。

## 互操作与增量边界

Handoff 现输出 `draft-template.json` 和带预校验命令的说明。核心 CLI 不会自动启动 Codex 或其他外部 Agent；因此本轮没有把“外部 Agent 已成功生成并导入 Draft”写成已验证事实。真实 Diff 没有受影响单元，生成的 refresh plan 是空的；没有为满足数量要求而伪造增量发布。后续人工或外部 Agent 可以使用模板运行 `learn import --dry-run` 后再决定是否导入、审核和发布。

## 限制

- 传播依据精确 hash 与结构化引用，不是语义理解。
- unchanged 不保证运行行为不变；verified Claim 仍需要目标版本运行证据。
- 不使用模糊相似度迁移 Evidence。
- Refresh Bundle 只面向已受影响 Topic，默认不超过 4000 估算 token。
- 尚未验证第二框架，也未证明真实 Token 节省。
