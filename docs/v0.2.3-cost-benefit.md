# v0.2.3 学习成本与复用收益

## 已知事实

- Published Knowledge：22。
- Evaluation tasks：12。
- 最终 Context 中复用知识选择：28。
- Raw fallback：36。
- 组件家族显式复核：3。
- 外部 Agent：1 个 Learning Draft 会话、1 个 Demo A、2 个 Demo B 会话。

## 启发式估计

12 个固定任务的 Raw Context estimated tokens mean 为 1844.5，Knowledge-first 为 1402.17。估计公式是 `ceil(characterCount / 4)`。该指标适合比较本系统输出字符规模，不是模型 tokenizer 的 usage。

## 实际会话数据

Demo B 的 Knowledge-first 会话 input tokens 高于 Raw，会话搜索命令更少但读取命令更多。这说明“Context 更短”与“整个 Coding Agent 会话 token 更少”不是同一命题。

## 成本模型

可审计字段：

- 学习：Bundle 数、Draft 数、review 数、published 数。
- 复用：任务数、selected unit 数、fallback 数。
- 维护：Gap 数、stale 数、conflict 数、待人工复核数。
- Agent：读取/搜索/命令、diff、lint/build、可获取的 session usage。

未记录人工分钟数，因此不估算人工成本、货币成本或 ROI。后续只有在多次真实外部项目任务中记录相同字段后，才适合讨论趋势。
