# GaitLogic 迁移门禁

## 进入条件

只有以下条件全部满足且获得明确迁移授权，才能进入 GaitLogic 重构或迁移：

- NCom 学习地图完成。
- 核心知识已绑定 commit 并经过验证。
- L0 至 L3 任务在目标环境稳定通过。
- 已有可重复的浏览器行为测试。
- 问题发现、最小复现、归因、知识更新和回归测试闭环已跑通。
- 已明确框架当前不适用或风险未知的能力。
- 迁移模块可独立部署、验证和回退。

满足技术门禁不等于自动获得生产系统修改权限。

## 迁移原则

- 不直接推翻现有前端，先选择低风险页面或模块。
- 第一阶段不修改后端接口。
- 新旧页面并存，保留明确路由或开关。
- 迁移前记录原页面行为基线，迁移后逐项对照。
- 每个模块具备独立回退路径和回退验证。
- 如实记录正面、负面和无结论结果，不以预期收益替代测量。

## 当前状态

当前仅建立门禁规范。尚未读取或修改 GaitLogic，未建立其行为基线，也未进入迁移阶段。
