# v0.1.6 TypeScript 符号与组件知识提取实施报告

日期：2026-07-23

## 实现

实现 `symbols extract/validate/list/query/diff`。Extractor 首先验证 Catalog、commit 和 tracked clean 状态，再只读取 `files.json` 登记且符合类别的 TypeScript/TSX 文件。语法阶段提取声明、成员、位置、规范化 signature、JSDoc、import/export；静态 resolver 处理相对模块和 workspace package。公共 API 通过 package 根 `index.ts` 的直接导出、named re-export、alias 和 export star 传播，并记录完整链。

组件检测由 `framework.yaml` 数据规则驱动，没有 NCom 分支。检测结合配置路径、基类、注册函数、公共导出、样式和示例信号。Props、events、slots 和生命周期只在存在明确结构证据时记录。

## 语义边界

TypeScript Program 使用 `noEmit/noResolve/noLib` 的受限 host，避免把 Catalog 外依赖正文作为分析输入。因此语义阶段可运行但会保留缺少全局库或外部声明产生的 diagnostics；语法结果始终保留。模块与公共 API 的主要解析由确定性 Catalog resolver 完成。

使用临时 Git/Catalog fixture 验证 TS/TSX、声明种类、成员、JSDoc、import/export、公共链、组件、查询、diff、dirty 拒绝和重复提取。旧 baseline/errors/knowledge/context/catalog 测试保持通过。
