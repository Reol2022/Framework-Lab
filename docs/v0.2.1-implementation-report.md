# Framework Lab v0.2.1 实施报告

v0.2.1 增加了由确定性 Learning Plan 驱动的知识发布工作流：Topic → bounded Bundle → 外部学习 Handoff → Draft → Evidence validation → 人工 review → Published Knowledge → coverage。核心没有调用 Codex 或 OpenAI API，也不修改框架源码或自动发布未经审核的结论。

Bundle 复用 v0.1.7 Retrieval 和 bounded source snippets；不会复制完整源码、完整文档或整个 Catalog。Draft、原始 Bundle、会话输出和完整 Snapshot 被 `.gitignore` 保持本地。Published Knowledge 只保存结构化总结、Claim、Scope 和 Evidence id。

`context create --knowledge-first` 在 Scope 匹配时加入 Published Knowledge，并记录 knowledge hit 与 raw fallback；该指标是字符量和启发式估算，不是实际 Codex Token 使用量。
